# 룬 순서 — 전투 시제품

`index.html`을 브라우저로 열면 바로 실행된다. 외부 파일 없음 (그림은 코드로 찍는 도트).

## 핵심 규칙 — 룬
- 룬은 불 · 서리 · 바람 세 가지. **보관 1칸 + 대기 5칸**, 합쳐서 각 2개씩. 같은 룬은 바로 이어 나오지 않는다.
- 스킬 1 · 2 · 3 중 무엇을 쓰든 **대기 맨 앞 룬**이 소모되고, 그 룬에 따라 효과가 달라진다.
- **R**: 보관 룬과 맨 앞 룬이 다르면 **교환**(재사용 대기 없음), 같으면 **공명**(둘을 함께 태우는 큰 기술, 재사용 7초).
- 대기 칸을 다 쓰면 1.4초 충전 뒤 새로 배열된다 (그동안 이동이 빨라진다).

| | 불 | 서리 | 바람 |
|---|---|---|---|
| 1 룬 탄환 | 맞으면 폭발 · 화상 | 첫 적을 얼림 | 빠르게 꿰뚫고 순풍 길(이동 속도) |
| 2 룬 진 | 불타는 바닥 | 범위 안 전부 얼림 | 즉시 터지며 밀어냄 |
| 3 룬 표식 | 넓고 큰 폭발 | 폭발 + 얼림 | 폭발 + 내 체력 회복 |
| R 공명 | 대화염(거대한 불덩이) | 빙결 폭풍(주변 전부 얼림) | 순풍의 축복(회복 · 보호막) |

## 조작
- PC: WASD · 방향키 이동, 마우스 조준, 1 2 3 스킬, R(스페이스) 교환 / 공명. 기본 공격은 자동
- 폰: 왼쪽 화면을 끌어 이동, 오른쪽 버튼으로 스킬 (가까운 적 자동 조준)
